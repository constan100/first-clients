# Examples

Real output from the First Clients skill.

## `first-clients-on-itself/`
The skill was run on its own repository (a free, open-source Claude skill with 0 users) on 26 Nov 2026, for a founder with 4 hours a week and no budget. The founder's answers came from a test persona.

| File | What it is |
|---|---|
| [`PLAN.md`](first-clients-on-itself/PLAN.md) | The one-page plan: what the founder actually follows |
| [`plan-data.json`](first-clients-on-itself/plan-data.json) | The same plan as data (the source for every export) |
| [`exports/`](first-clients-on-itself/exports/) | The plan as Excel tracker, PowerPoint, Word, CSV and printable HTML |

What it found first, before any marketing: the public repo was behind the local version, the README install command had a `<your-username>` placeholder, there was no sample output anywhere (this folder fixes that), and there was no way for users to give feedback.

The list of people to contact (`targets.md`) is left out on purpose: it contains personal data.

Want an example for your kind of product? Open an issue, or run the skill and share your (cleaned-up) `PLAN.md`.
